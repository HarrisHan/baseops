# BaseOps Launch Playbook

## Product Bet

BaseOps should win by being the safest and fastest way to clean up Properties and Bases workflows. The core promise is not "more power"; it is "bulk edits without fear."

## Pre-Submission

- Recruit 10-20 beta users through the Obsidian forum, Discord, and Reddit.
- Ask each beta user to try one workflow:
  - Create starter kit.
  - Select active folder notes.
  - Open property report.
  - Apply one preset.
  - Undo the operation.
- Collect the confusing steps and fix onboarding before community submission.
- Publish a short GIF or video showing preview, apply, undo.

## Community Submission Copy

Short description:

> Preview, apply, and undo batch property operations for notes managed with Obsidian Bases and Properties.

Announcement title:

> BaseOps: safe batch edits for Obsidian Bases and Properties

Announcement body:

> BaseOps adds a local-first action layer for Obsidian Bases. Select notes with a checkbox property, load a workflow preset, preview every frontmatter change, apply it, and undo the latest operation in the same session. It also includes a property report so you can spot stale fields and inconsistent statuses before editing.

## Growth Loops

- Starter kit makes the first run obvious.
- Presets turn one successful edit into repeated use.
- Property report gives users a reason to open the plugin even before editing.
- Local-only safety makes the plugin easier to recommend in privacy-conscious Obsidian communities.

## Next High-Leverage Features

1. Custom Bases view with toolbar actions.
2. Saved schema checks for required properties and allowed values.
3. Import/export presets as Markdown snippets.
4. One-click BRAT beta install instructions.
5. Short video assets for forum and Reddit launch posts.

## Review Checklist

- Keep the plugin network-free.
- Keep destructive operations out of scope.
- Keep every bulk write behind preview.
- Keep README examples concrete and short.
- Keep release tags aligned with `manifest.json`.
