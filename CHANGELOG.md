# Changelog

## 0.4.2

- Preserved `node:` built-in imports in test bundles and moved CI runners to Node 24.

## 0.4.1

- Fixed GitHub Actions test bundling across Node runner versions.

## 0.4.0

- Added GitHub Actions CI for test, build, and release checks.
- Added automatic GitHub release workflow for version tags.
- Added a release validation script for Obsidian assets, version alignment, manifest rules, and runtime safety checks.
- Added launch and growth playbook.

## 0.3.0

- Added property report command.
- Summarizes property coverage, selected-note coverage, missing counts, and common values.
- Added tests for property summary logic.

## 0.2.0

- Added built-in workflow presets.
- Added user-saved presets.
- Added current folder selection command.
- Added starter kit command for quick onboarding.

## 0.1.0

- Initial local-first bulk property editor.
- Preview before apply.
- Add, remove, replace, and clear operations.
- In-memory undo for the latest operation.
